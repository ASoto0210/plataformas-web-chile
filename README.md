# Plataformas Web Chile — Kit de logo

Dirección elegida: **Capas** (tres planos que ascienden = una plataforma que te eleva).

## Archivos

| Archivo | Uso |
|---|---|
| `icono-color.svg` | Símbolo a color (azul + teal). Uso general. |
| `icono-blanco.svg` | Símbolo blanco, para fondos oscuros. |
| `icono-negro.svg` | Símbolo tinta, para fondos claros. |
| `logo-horizontal-oscuro.svg` | Ícono + texto, fondo oscuro. Header web, firmas. |
| `logo-horizontal-claro.svg` | Ícono + texto, fondo claro. |
| `logo-vertical-oscuro.svg` | Ícono arriba, texto abajo (centrado). |
| `avatar-instagram.svg` | Avatar 320×320 (fondo degradado). IG / FB / Google. |
| `favicon.svg` | Ícono redondeado para pestaña del navegador. |

## Colores

| Nombre | HEX | Uso |
|---|---|---|
| Tinta | `#0B1220` | Fondos oscuros / texto |
| Azul (acento) | `#2F6BFF` | Capa base, color principal |
| Azul suave | `#5B8CFF` | Capa media |
| Teal (capa) | `#2CE4C4` | Capa superior, detalle |
| Neutro claro | `#EAF0FA` | Texto sobre oscuro |
| Apagado | `#8A97AD` | Texto secundario ("Web") |

Variantes para fondo claro: azul `#245BE0`, teal `#12B79B`.

## Nota técnica importante

El texto del wordmark (los archivos `logo-horizontal-*` y `logo-vertical-*`) usa fuentes del
sistema (Segoe UI / Consolas). Para producción profesional conviene **convertir el texto a
trazos (outlines)** para que se vea idéntico en cualquier equipo. Se puede hacer gratis en
Inkscape (Trazo → Objeto a trayecto) o en un editor vectorial. El símbolo (los `icono-*`)
ya es 100% geométrico y no depende de fuentes.

## Exportar a PNG

Desde el navegador (o Inkscape / Figma) se puede exportar cada SVG a PNG en el tamaño que se
necesite: 512×512 para el ícono, 320×320 para el avatar de IG, 32×32 y 180×180 para favicon.
